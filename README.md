# Matrix Loader

## О проекте
Асинхронная Python-библиотека для загрузки квадратной матрицы с удалённого сервера и её обхода по спирали против часовой стрелки, начиная с левого верхнего угла.

## Ссылка на исходное задание
[Avito Tech: Python Trainee Assignment](https://github.com/avito-tech/python-trainee-assignment)

## Что сделано
- Реализована асинхронная функция `get_matrix(url)` с использованием библиотеки `httpx`.
- Написан устойчивый парсер текста.
- Реализован алгоритм спирального обхода матрицы против часовой стрелки для любой размерности N.
- Встроен самопроверяющийся тест-кейс из условий задачи в блок `if __name__ == "__main__":`.

## Что не сделано
- Базовая обработка сетевых и HTTP-ошибок.

## Как запустить
1. Установите зависимость `httpx`:
   pip install httpx
1. Установите зависимость `asyncio`:
   pip install asyncio
3. Запустите скрипт для проверки:
   python matrix_loader.py
